## 1. CSV transaction import (batch & single row)

**Shape:** append‑only rows, a `Long` surrogate key, *create* audit only (a trade is written once,
never updated) — a `BaseEntity<Long>` implementing `CreateAudit`. The auditor is a job name, not a user.

### 1.1 Entity

```java
import com.gothamdude.core.jdbc.model.BaseEntity;
import com.gothamdude.core.jdbc.model.CreateAudit;
import lombok.Getter;
import lombok.Setter;
import java.math.BigDecimal;
import java.time.Instant;
import java.time.LocalDate;

@Getter @Setter   // Lombok generates getId/setId + the CreateAudit + business accessors
public class Trade extends BaseEntity<Long> implements CreateAudit {   // append-only, create-audit
    private Long id;
    private String symbol;
    private BigDecimal price;
    private int quantity;
    private LocalDate tradeDate;
    private Instant createdTs;
    private String createdBy;
}
```

```sql
CREATE TABLE trade (
    id          BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    symbol      VARCHAR(16)  NOT NULL,
    price       NUMERIC(18,4) NOT NULL,
    quantity    INT          NOT NULL,
    trade_date  DATE         NOT NULL,
    created_ts  TIMESTAMPTZ  NOT NULL,
    created_by  VARCHAR(64)  NOT NULL
);
```

### 1.2 Repository

```java
@Repository
public class TradeRepository extends AbstractJdbcRepository<Trade, Long> {

    public TradeRepository(NamedParameterJdbcTemplate template,
                           Clock clock,
                           AuditorProvider auditorProvider) {
        super(template, clock, auditorProvider);   // use the audited constructor
    }

    @Override protected String getTableName() { return "trade"; }

    @Override protected String getInsertSql() {
        return "INSERT INTO trade (symbol, price, quantity, trade_date, created_ts, created_by) " +
               "VALUES (:symbol, :price, :quantity, :tradeDate, :createdTs, :createdBy)";
    }

    // :createdTs / :createdBy are contributed automatically (CreateAudit).
    @Override protected MapSqlParameterSource getInsertParams(Trade t) {
        return new MapSqlParameterSource()
                .addValue("symbol", t.getSymbol())
                .addValue("price", t.getPrice())
                .addValue("quantity", t.getQuantity())
                .addValue("tradeDate", t.getTradeDate());
    }

    @Override protected RowMapper<Trade> getRowMapper() {
        return (rs, i) -> {
            Trade t = new Trade();
            t.setId(rs.getLong("id"));
            t.setSymbol(rs.getString("symbol"));
            t.setPrice(rs.getBigDecimal("price"));
            t.setQuantity(rs.getInt("quantity"));
            t.setTradeDate(rs.getObject("trade_date", LocalDate.class));
            t.setCreatedTs(rs.getTimestamp("created_ts").toInstant());
            t.setCreatedBy(rs.getString("created_by"));
            return t;
        };
    }

}
```

> Trades are append‑only, so there is no update path. For **reference data** you reload (e.g. process
> definitions), override `getUpsertSql()` with an `INSERT … ON CONFLICT (<natural key>) DO UPDATE …`
> keyed on a business column — not the generated `id` — and load it with `upsertBatch(...)`.

### 1.5 Batch insert with chunked commits and a reject file

`insertBatch` runs **one** JDBC batch and joins the caller's transaction. Keep the chunking, the
commit boundary and the reject routing in *your* service — the library intentionally does not add
retry/skip logic.

```java
@Service
public class TradeImportService {

    private static final int CHUNK = 2_000;   // 2k–5k rows is a good default

    private final TradeRepository trades;
    private final TransactionTemplate tx;     // new transaction per chunk

    public TradeImportService(TradeRepository trades, PlatformTransactionManager tm) {
        this.trades = trades;
        this.tx = new TransactionTemplate(tm);
        this.tx.setPropagationBehavior(TransactionDefinition.PROPAGATION_REQUIRES_NEW);
    }

    public ImportReport importFile(Stream<Trade> rows) {
        ImportReport report = new ImportReport();
        List<Trade> chunk = new ArrayList<>(CHUNK);

        Iterator<Trade> it = rows.iterator();
        while (it.hasNext()) {
            chunk.add(it.next());
            if (chunk.size() == CHUNK) { flush(chunk, report); chunk.clear(); }
        }
        if (!chunk.isEmpty()) flush(chunk, report);
        return report;
    }

    private void flush(List<Trade> chunk, ImportReport report) {
        try {
            int[] counts = tx.execute(status -> trades.insertBatch(chunk));
            report.addLoaded(counts.length);
        } catch (CoreJdbcException e) {
            // Whole chunk rolled back. Classify and route to the reject file.
            switch (e.getErrorCode()) {
                case DUPLICATE_KEY, CONSTRAINT_VIOLATION -> report.reject(chunk, e.getErrorCode());
                default -> throw e;   // genuine fault — fail the import
            }
        }
    }
}
```

> **Tip:** if you need *per‑row* reject granularity rather than per‑chunk, retry the failed chunk
> row‑by‑row with `insert(...)` inside its own `REQUIRES_NEW` transaction and collect the individual
> failures.

### 1.6 Calling a stored procedure (`SimpleJdbcCall`)

Stored procedures use Spring's **`SimpleJdbcCall`**, which you build from the repository's exposed
`jdbcTemplate` (the `NamedParameterJdbcTemplate` has no call support). `SimpleJdbcCall` compiles and
caches the procedure's metadata on first use, so build it **once** (in the constructor) and reuse the
instance — don't `new` one per call. Its `execute(SqlParameterSource)` accepts a
`MapSqlParameterSource`, so IN parameters read in the same named style as the rest of the library.

Given a settlement procedure:

```sql
CREATE PROCEDURE settle_trades(IN trade_date DATE, OUT settled_count INT) ...
```

```java
@Repository
public class TradeRepository extends AbstractJdbcRepository<Trade, Long> {

    private final SimpleJdbcCall settleCall;

    public TradeRepository(NamedParameterJdbcTemplate template, Clock clock, AuditorProvider auditor) {
        super(template, clock, auditor);
        // `jdbcTemplate` is exposed by the base class — the same backing template as
        // `namedParameterJdbcTemplate`, so nothing extra is wired. Compile the call once.
        this.settleCall = new SimpleJdbcCall(jdbcTemplate).withProcedureName("settle_trades");
    }

    /** Settle all trades for a business date; returns how many were settled. */
    public int settle(LocalDate businessDate) {
        try {
            Map<String, Object> out = settleCall.execute(
                    new MapSqlParameterSource("trade_date", businessDate));
            // Read OUT params through Number, not a direct (int)/(Integer) cast:
            // the result type differs by driver (Oracle NUMBER -> BigDecimal,
            // PostgreSQL/SQL Server INT -> Integer).
            return ((Number) out.get("settled_count")).intValue();
        } catch (DataAccessException e) {
            // Optional: route proc failures through the same ErrorCode machinery as CRUD.
            throw translate(e, "settle_trades failed");
        }
    }

    // … getTableName, getRowMapper, getInsertSql, getInsertParams as in 1.1 / 1.2
}
```

The constructor from 1.2 already takes the audited `(template, clock, auditor)` form, so no change is
needed there — you just add the compiled `SimpleJdbcCall` field alongside it.

#### Portability across PostgreSQL / SQL Server / Oracle

The `SimpleJdbcCall` approach works on all three, but adjust for these database differences:

- **OUT scalar type:** always read via `((Number) out.get(name)).intValue()`. Oracle `NUMBER` comes back
  as `BigDecimal`; a direct `(Integer)` cast fails there.
- **PostgreSQL — procedure vs function:** if the object is a `FUNCTION` (or a `PROCEDURE` on PG ≤ 13,
  which can't have `OUT` params), use `.withFunctionName("…")` + `executeFunction(...)`. Real
  `PROCEDURE` with `OUT` works on PG 14+.
- **Oracle — packages:** add `.withCatalogName("TRADE_PKG")` (Spring maps "catalog" to the Oracle
  package). For a `REF CURSOR` result, add `.returningResultSet("rows", rowMapper)`.
- **Identifier case / metadata:** Spring upper-cases names for metadata lookup, which suits Oracle and
  SQL Server. PostgreSQL stores names lower-case, so for maximum portability skip metadata and declare
  parameters explicitly:

  ```java
  new SimpleJdbcCall(jdbcTemplate)
      .withProcedureName("settle_trades")
      .withoutProcedureColumnMetaDataAccess()
      .declareParameters(
          new SqlParameter("trade_date", Types.DATE),
          new SqlOutParameter("settled_count", Types.INTEGER));
  ```

  The explicit form is also the most robust choice when a procedure is overloaded or lives behind a
  non‑default schema.

## 2. Event‑management API

**Shape:** mutable, audited, soft‑deletable, concurrently edited records with a database‑generated
key. Use `DomainEntity<Long>` (= `Auditable` + `SoftDeletable`) and add `Versionable` for optimistic
locking. The auditor is the authenticated user; `POST` must return the new id.

### 2.1 Entity

```java
import com.gothamdude.core.jdbc.model.DomainEntity;
import com.gothamdude.core.jdbc.model.Versionable;

public class Event extends DomainEntity<Long> implements Versionable {
    private Long id;
    private String name;
    private Instant startsAt;
    private long version;

    @Override public Long getId() { return id; }
    @Override public void setId(Long id) { this.id = id; }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public Instant getStartsAt() { return startsAt; }
    public void setStartsAt(Instant startsAt) { this.startsAt = startsAt; }
    @Override public long getVersion() { return version; }
    @Override public void setVersion(long version) { this.version = version; }
}
```

```sql
CREATE TABLE event (
    id         BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name       VARCHAR(255) NOT NULL,
    starts_at  TIMESTAMPTZ  NOT NULL,
    created_ts TIMESTAMPTZ  NOT NULL,
    created_by VARCHAR(64)  NOT NULL,
    updated_ts TIMESTAMPTZ  NOT NULL,
    updated_by VARCHAR(64)  NOT NULL,
    active     BOOLEAN      NOT NULL DEFAULT TRUE,
    version    BIGINT       NOT NULL DEFAULT 0
);
```

### 2.2 Repository

```java
@Repository
public class EventRepository extends AbstractJdbcRepository<Event, Long> {

    public EventRepository(NamedParameterJdbcTemplate t, Clock c, AuditorProvider a) { super(t, c, a); }

    @Override protected String getTableName() { return "event"; }
    @Override protected boolean isSoftDelete() { return true; }   // deleteById → deactivate

    @Override protected String getInsertSql() {
        return "INSERT INTO event (name, starts_at, created_ts, created_by, updated_ts, updated_by, active, version) " +
               "VALUES (:name, :startsAt, :createdTs, :createdBy, :updatedTs, :updatedBy, :active, :version)";
    }
    @Override protected MapSqlParameterSource getInsertParams(Event e) {
        return new MapSqlParameterSource().addValue("name", e.getName()).addValue("startsAt", e.getStartsAt());
    }

    @Override protected String getUpdateSql() {
        return "UPDATE event SET name=:name, starts_at=:startsAt, updated_ts=:updatedTs, updated_by=:updatedBy, " +
               "version=version+1 WHERE id=:id AND version=:version";   // optimistic lock
    }
    @Override protected MapSqlParameterSource getUpdateParams(Event e) {
        return new MapSqlParameterSource()
                .addValue("name", e.getName()).addValue("startsAt", e.getStartsAt()).addValue("id", e.getId());
    }

    @Override protected String getFindByIdSql() { return "SELECT * FROM event WHERE id=:id"; }
    @Override protected String getFindAllSql()  { return "SELECT * FROM event ORDER BY starts_at"; }
    @Override protected String getCountSql()    { return "SELECT COUNT(*) FROM event"; }
    @Override protected MapSqlParameterSource getIdParam(Long id) { return new MapSqlParameterSource("id", id); }

    @Override protected RowMapper<Event> getRowMapper() {
        return (rs, i) -> {
            Event e = new Event();
            e.setId(rs.getLong("id"));
            e.setName(rs.getString("name"));
            e.setStartsAt(rs.getTimestamp("starts_at").toInstant());
            e.setCreatedTs(rs.getTimestamp("created_ts").toInstant());
            e.setCreatedBy(rs.getString("created_by"));
            e.setUpdatedTs(rs.getTimestamp("updated_ts").toInstant());
            e.setUpdatedBy(rs.getString("updated_by"));
            e.setActive(rs.getBoolean("active"));
            e.setVersion(rs.getLong("version"));
            return e;
        };
    }

    // Active-only, paged listing — compose activePredicate() into the finder.
    public PageResult<Event> findActive(PageRequest page) {
        List<Event> rows = queryList(
            "SELECT * FROM event WHERE 1=1" + activePredicate() + " ORDER BY starts_at LIMIT :limit OFFSET :offset",
            params("limit", page.limit(), "offset", page.offset()));
        long total = queryScalar("SELECT COUNT(*) FROM event WHERE 1=1" + activePredicate(),
                                 params(), Long.class).orElse(0L);
        return new PageResult<>(rows, page.limit(), page.offset(), total);
    }

    // Projection across a join table — the result is NOT an Event.
    public List<SpeakerView> findSpeakers(long eventId) {
        return queryList(
            "SELECT s.name, s.bio FROM speaker s JOIN event_speaker es ON es.speaker_id = s.id WHERE es.event_id = :eventId",
            params("eventId", eventId),
            (rs, i) -> new SpeakerView(rs.getString("name"), rs.getString("bio")));
    }
}
```

### 2.4 Controller — create returns the generated id

```java
@PostMapping("/events")
ResponseEntity<Event> create(@RequestBody Event event) {
    Long id = eventRepository.insertAndReturnKey(event);   // id is also set on `event`
    return ResponseEntity.created(URI.create("/events/" + id)).body(event);
}

@GetMapping("/events")
PageResult<Event> list(@RequestParam(defaultValue = "20") int limit,
                       @RequestParam(defaultValue = "0") int offset) {
    return eventRepository.findActive(new PageRequest(limit, offset));
}

@PutMapping("/events/{id}")
Event update(@PathVariable long id, @RequestBody Event event) {
    event.setId(id);
    eventRepository.update(event);   // throws OPTIMISTIC_LOCK if the client's version is stale
    return event;
}

@DeleteMapping("/events/{id}")
ResponseEntity<Void> delete(@PathVariable long id) {
    eventRepository.deleteById(id);  // soft delete: active=false, audit bumped
    return ResponseEntity.noContent().build();
}
```

### 2.5 Map errors to HTTP once

```java
@RestControllerAdvice
class ApiExceptionHandler {
    @ExceptionHandler(CoreJdbcException.class)
    ResponseEntity<Object> handle(CoreJdbcException ex) {
        HttpStatus status = switch (ex.getErrorCode()) {
            case NOT_FOUND -> HttpStatus.NOT_FOUND;                                        // 404
            case DUPLICATE_KEY, CONSTRAINT_VIOLATION, OPTIMISTIC_LOCK -> HttpStatus.CONFLICT; // 409
            default -> HttpStatus.INTERNAL_SERVER_ERROR;                                   // 500
        };
        return ResponseEntity.status(status)
                .body(Map.of("error", ex.getErrorCode().name(), "message", ex.getMessage()));
    }
}
```

So two admins editing the same event concurrently get a clean `409 Conflict` (stale `version`)
instead of silently clobbering each other, and a missing event yields `404`.

## 3. Auction

Two tables with different needs:

- **Auction item** — a mutable, versioned record (its *current highest bid* changes under
  contention). Use `Versionable` to prevent two bids from racing.
- **Bid** — append‑only, keyed by *(item, bidder)* so a bidder has one standing bid per item. A
  [composite key](./README.md#composite-keys) with *create* audit only.

### 3.1 Auction item (optimistic locking under bid contention)

```java
public class AuctionItem extends DomainEntity<Long> implements Versionable {
    private Long id;
    private String title;
    private BigDecimal highestBid;
    private long version;
    // getId/setId, getTitle/setTitle, getHighestBid/setHighestBid, getVersion/setVersion …
}
```

```java
@Repository
public class AuctionItemRepository extends AbstractJdbcRepository<AuctionItem, Long> {
    public AuctionItemRepository(NamedParameterJdbcTemplate t, Clock c, AuditorProvider a) { super(t, c, a); }

    @Override protected String getTableName() { return "auction_item"; }

    @Override protected String getUpdateSql() {
        return "UPDATE auction_item SET highest_bid=:highestBid, updated_ts=:updatedTs, updated_by=:updatedBy, " +
               "version=version+1 WHERE id=:id AND version=:version";
    }
    @Override protected MapSqlParameterSource getUpdateParams(AuctionItem i) {
        return new MapSqlParameterSource()
                .addValue("highestBid", i.getHighestBid()).addValue("id", i.getId());
    }
    @Override protected String getFindByIdSql() { return "SELECT * FROM auction_item WHERE id=:id"; }
    @Override protected MapSqlParameterSource getIdParam(Long id) { return new MapSqlParameterSource("id", id); }
    // getRowMapper, getInsertSql, getInsertParams …
}
```

Raising the highest bid safely — retry on a lost race:

```java
@Service
public class BiddingService {
    private final AuctionItemRepository items;
    private final BidRepository bids;

    public void placeBid(long itemId, UUID bidder, BigDecimal amount) {
        for (int attempt = 0; attempt < 3; attempt++) {
            AuctionItem item = items.findById(itemId)
                    .orElseThrow(() -> new CoreJdbcException(ErrorCode.NOT_FOUND, "no item " + itemId));
            if (item.getHighestBid() != null && amount.compareTo(item.getHighestBid()) <= 0) {
                throw new IllegalArgumentException("bid must exceed current highest");
            }
            item.setHighestBid(amount);
            try {
                items.update(item);                       // OPTIMISTIC_LOCK if someone bid first
                bids.upsert(new Bid(itemId, bidder, amount));
                return;
            } catch (CoreJdbcException e) {
                if (e.getErrorCode() == ErrorCode.OPTIMISTIC_LOCK) continue;  // reread and retry
                throw e;
            }
        }
        throw new CoreJdbcException(ErrorCode.OPTIMISTIC_LOCK, "too much contention on item " + itemId);
    }
}
```

### 3.2 Bid (composite key, append/upsert)

```java
public record BidId(long itemId, java.util.UUID bidderId) {}

public class Bid extends BaseEntity<BidId> implements CreateAudit {
    private BidId id;
    private BigDecimal amount;
    private Instant createdTs;
    private String createdBy;

    public Bid() {}
    public Bid(long itemId, UUID bidderId, BigDecimal amount) {
        this.id = new BidId(itemId, bidderId); this.amount = amount;
    }
    @Override public BidId getId() { return id; }
    @Override public void setId(BidId id) { this.id = id; }
    public BigDecimal getAmount() { return amount; }
    public void setAmount(BigDecimal amount) { this.amount = amount; }
    @Override public Instant getCreatedTs() { return createdTs; }
    @Override public void setCreatedTs(Instant ts) { this.createdTs = ts; }
    @Override public String getCreatedBy() { return createdBy; }
    @Override public void setCreatedBy(String by) { this.createdBy = by; }
}
```

```sql
CREATE TABLE bid (
    item_id    BIGINT       NOT NULL,
    bidder_id  UUID         NOT NULL,
    amount     NUMERIC(18,2) NOT NULL,
    created_ts TIMESTAMPTZ  NOT NULL,
    created_by VARCHAR(64)  NOT NULL,
    PRIMARY KEY (item_id, bidder_id)
);
```

```java
@Repository
public class BidRepository extends AbstractJdbcRepository<Bid, BidId> {
    public BidRepository(NamedParameterJdbcTemplate t, Clock c, AuditorProvider a) { super(t, c, a); }

    @Override protected String getTableName() { return "bid"; }

    @Override protected String getInsertSql() {
        return "INSERT INTO bid (item_id, bidder_id, amount, created_ts, created_by) " +
               "VALUES (:itemId, :bidderId, :amount, :createdTs, :createdBy) " +
               "ON CONFLICT (item_id, bidder_id) DO UPDATE SET amount = EXCLUDED.amount";
    }
    @Override protected MapSqlParameterSource getInsertParams(Bid b) {
        return new MapSqlParameterSource()
                .addValue("itemId", b.getId().itemId())
                .addValue("bidderId", b.getId().bidderId())
                .addValue("amount", b.getAmount());
    }

    @Override protected String getFindByIdSql() {
        return "SELECT * FROM bid WHERE item_id=:itemId AND bidder_id=:bidderId";
    }
    @Override protected MapSqlParameterSource getIdParam(BidId id) {
        return new MapSqlParameterSource().addValue("itemId", id.itemId()).addValue("bidderId", id.bidderId());
    }

    @Override protected RowMapper<Bid> getRowMapper() {
        return (rs, i) -> {
            Bid b = new Bid(rs.getLong("item_id"), rs.getObject("bidder_id", UUID.class), rs.getBigDecimal("amount"));
            b.setCreatedTs(rs.getTimestamp("created_ts").toInstant());
            b.setCreatedBy(rs.getString("created_by"));
            return b;
        };
    }

    public void upsert(Bid b) { insert(b); }   // insert SQL already upserts on the composite key

    public List<Bid> findByItem(long itemId) {
        return queryList("SELECT * FROM bid WHERE item_id=:itemId ORDER BY amount DESC", params("itemId", itemId));
    }
}
```

## Choosing the mixins for a new table

Pick the row that matches the table; implement those interfaces (or extend the matching convenience
class). No core change is ever required.

| Table kind | `CreateAudit` | `UpdateAudit` | `SoftDeletable` | `Versionable` | Start from |
|---|:---:|:---:|:---:|:---:|---|
| Trade / append‑only log | ✅ | | | | `BaseEntity<Long>` + `CreateAudit` |
| Auction bid | ✅ | | | | `BaseEntity` + `CreateAudit` (composite id) |
| Process log / event registration | ✅ | ✅ | | | `AuditedEntity` |
| Reference data (business dates) | ✅ | ✅ | | | `AuditedEntity` |
| Event / Speaker / Location | ✅ | ✅ | ✅ | ✅ | `DomainEntity` + `Versionable` |
| Event joiner | ✅ | | ✅ | | `BaseEntity` + `CreateAudit` + `SoftDeletable` |
| Auction item | ✅ | ✅ | ✅ | ✅ | `DomainEntity` + `Versionable` |

Reminder: once an entity implements a mixin, the matching
[reserved parameters](./README.md#reserved-parameter-names-automatic-audit)
(`:createdTs`, `:createdBy`, `:updatedTs`, `:updatedBy`, `:active`, `:version`) are contributed
automatically — reference them in your SQL and leave them out of your param maps.
